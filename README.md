# HDOFOOT ⚽

HDOFOOT is a responsive football streaming and match-information web app built with Next.js and TypeScript.

## Features

- ⚽ Football home page
- 🔴 Live matches
- 📅 Fixtures
- 🏆 Leagues
- 👥 Teams
- 📺 IPTV
- 🎬 Movies
- 📺 TV Shows
- ▶️ Videos
- WWE section
- Live match streaming/player support
- API-Football integration
- Responsive mobile and desktop interface
- Android TV / D-pad navigation support
- Mobile bottom navigation
- Desktop sidebar navigation
- TV-friendly focus states

## Technology

- Next.js
- React
- TypeScript
- Tailwind CSS
- API-Football
- HLS playback
- Emby integration
